Módulo 1 — Fundamentos: Esperança, Variância e Propriedades

1.1 Esperança (média)

Uma variável aleatória X é um número que depende do acaso. A esperança E(X) é o "centro de gravidade" da distribuição — o valor médio esperado.

Discreto: E(X) = soma de [ x · P(X = x) ]
Contínuo: E(X) = int de [ x · f(x) ] dx

1.2 Variância

Mede o espalhamento em torno da média. Fórmula mais usada:

Var(X) = E(X2) − [E(X)]2

Desvio-padrão: σ = sqrt( Var(X) ) — na mesma unidade dos dados.

1.3 Propriedades (DECORE!)

Sejam a e b constantes:

EsperançaVariância
E(a) = aVar(a) = 0
E(aX) = a · E(X)Var(aX) = a2 · Var(X)
E(X + b) = E(X) + bVar(X + b) = Var(X)
E(aX + b) = a · E(X) + bVar(aX + b) = a2 · Var(X)
E(X+Y) = E(X)+E(Y) (sempre)Var(X+Y) = Var(X)+Var(Y) (se independentes)
Duas ideias que sempre caem:
1. Somar constante desloca a média mas NÃO muda a variância.
2. Multiplicar por constante multiplica a média por a e a variância por a2 (o quadrado!).

Lista 1 — Questão 2

O que acontece com a média e a variância quando: (i) multiplica cada observação por 2? (ii) soma 10 a cada observação?

(i) Y = 2X (a=2): média E(2X) = 2·E(X) DOBRA; variância Var(2X) = 22·Var(X) = 4·Var(X).

(ii) Y = X + 10 (b=10): média E(X+10) = E(X)+10 aumenta em 10; variância Var(X+10) = Var(X) (não muda).

Intuição: somar 10 move a régua inteira — o formato da nuvem continua igual. Multiplicar por 2 "estica" a nuvem, aumentando o espalhamento.

Lista 1 — Questão 1

Na empresa A, a média salarial é 10.000 e o 3o quartil é 5.000.

Quartil: o 3o quartil (Q3) deixa 75% dos dados abaixo dele. Aqui Q3 = 5.000 mas a média = 10.000: 75% ganham ate 5.000, mas poucos salários altíssimos puxam a média para cima. Distribuição assimétrica à direita.

(a) P(X <= 5.000) = 0,75 e P(X > 5.000) = 0,25. É muito mais provável ganhar MENOS que 5.000 (75%).

(b) Empresa B: média 7.000, variância aprox. 0 = quase todos ganham ~7.000. Empresa A: média 10.000 mas 75% ganham ate 5.000.

Resposta: Escolher a Empresa B. Apesar da média menor, a variância nula garante ganhar ~7.000. Na A, um salário sorteado ao acaso provavelmente seria baixo. A média sozinha engana — é preciso olhar dispersão e assimetria.

Módulo 2 — Valor Esperado como Critério de Decisão

Sob incerteza, calcule a média ponderada dos resultados pelas probabilidades e escolha a opção com maior lucro esperado.

E(Lucro) = soma de [ (resultadoi) × P(resultadoi) ]
Prejuízo é valor NEGATIVO. Prejuízo de 30.000 entra como −30.000.

Lista 1 — Questão 3

Obra 1: lucro 120.000 (prob 3/4) ou prejuízo 30.000 (prob 1/4). Obra 2: lucro 180.000 (prob 1/2) ou prejuízo 45.000 (prob 1/2). Qual escolher?

Obra 1: E(L1) = 120.000·(3/4) + (−30.000)·(1/4) = 90.000 − 7.500 = 82.500

Obra 2: E(L2) = 180.000·(1/2) + (−45.000)·(1/2) = 90.000 − 22.500 = 67.500

Resposta: Escolher a Obra 1 (82.500 > 67.500). A Obra 2 ainda é mais arriscada (maior variância).

Destaques que caem muito:
• Poisson: média = variância = θ.
• Normal — padronização: Z = (X − μ)/σ, depois consulta a tabela Z.

• β = média (escala): f(x) = (1/β)e−x/β, E=β, Var=β2.

Módulo 4 — Funções de Distribuição (FDA/CDF) e Densidades

4.1 Dois objetos ligados

Densidade f(x): probabilidade sai integrando: P(a <= X <= b) = int de a até b de f(x) dx.

Acumulada (CDF): F(x) = P(X <= x) = int de menos infinito até x de f(t) dt.

f(x) = derivada de F(x)   (a densidade é a derivada da acumulada)

4.2 As duas propriedades de toda densidade

(1) f(x) >= 0     (2) int de f(x) dx = 1  (área total = 1)

A propriedade (2) serve para achar constantes desconhecidas.

Lista 3 — Questão 1

f(x) = βx(4−x) para 0 < x < 4, com β > 0. Determine β.

Impor int de 0 a 4 de βx(4−x) dx = 1. Expandindo x(4−x) = 4x − x2:

β · [2x2 − x3/3] de 0 a 4 = β · (32 − 64/3) = β · (32/3) = 1
β = 3/32

Lista 3 — Questão 4

f(x) = k · e−kx · I(x>0), com k>0. Mostre que é fdp e calcule P(X>2).

É a Exponencial de taxa k. (1) f >= 0 OK. (2) int de 0 a infinito de k·e−kx dx = 1 OK. Logo é fdp.

P(X > 2) = int de 2 a infinito de k·e−kx dx = e−2k

Confirma a regra da cauda: P(X>x) = e−taxa·x.

4.3 CDF do MÁXIMO e do MÍNIMO (fundamental!)

Para X1,...,Xn iid com CDF F(x):

Fmáx(x) = [F(x)]n      Fmín(x) = 1 − [1−F(x)]n

Máximo: "máx <= x" quer dizer TODOS <= x = produto = [F(x)]n.
Mínimo: "mín > x" quer dizer TODOS > x = [1−F(x)]n.

Módulo 5 — Função Geradora de Momentos (FGM): o tema MAIS importante

MX(t) = E( etX )

Discreta: soma de etx·P(X=x).   Contínua: int de etx·f(x) dx.

Os 4 superpoderes da FGM

  1. Gera momentos: E(X) = M'(0), E(X2) = M''(0), então Var(X) = M''(0) − [M'(0)]2.
  2. Unicidade: cada distribuição tem FGM única = identifica a distribuição.
  3. Soma de independentes = PRODUTO das FGMs: Msoma(t) = produto de MXi(t).
  4. Transformação linear: MaX+b(t) = ebt · MX(at).

Sempre M(0) = 1 (serve de checagem).

Tabela de FGMs (decore as principais)

DistribuiçãoFGM M(t)
Poisson(θ)eθ(et − 1)
Normal(μ,σ2)eμt + (1/2)σ2t2
Exponencial (taxa λ)λ/(λ − t),  t<λ
Exponencial (média β)1/(1 − βt),  t<1/β
Gama(α, λ) — taxa λ[λ/(λ − t)]α
Binomial(n,θ)(1 − θ + θet)n
Padrão Exp -> Gama: a FGM da Gama é a da Exponencial elevada a α. É a chave da soma de exponenciais (Erlang).

Lista 1 — Questão 5 (teórica) — resposta modelo

A FGM de X é MX(t) = E(etX), definida numa vizinhança de t=0. Propriedades: (1) a k-ésima derivada em 0 dá E(Xk); (2) unicidade; (3) soma de independentes é produto das FGMs; (4) MaX+b(t) = ebtMX(at); (5) M(0)=1.

Lista 3 — Questão 2

X ~ Exp(4). Determine rigorosamente a FGM e calcule Var(X).

Taxa λ=4, f(x)=4e−4x. Pela definição:

M(t) = int de 0 a inf de etx·4e−4x dx = 4 · int de e−(4−t)x dx = 4/(4−t),  t<4

Checagem: M(0)=4/4=1 OK. Derivando: M'(t)=4(4−t)−2, M'(0)=4/16=1/4 = E(X). M''(t)=8(4−t)−3, M''(0)=8/64=1/8 = E(X2).

Var(X) = 1/8 − (1/4)2 = 1/8 − 1/16 = 1/16

Confere: Exp taxa 4 tem E=1/4, Var=1/16.

Módulo 7 — Transformações de Variáveis (distribuição de Y = g(X))

Método da FDA (o mais seguro): 1. FY(y)=P(g(X)<=y). 2. Isole X. 3. Substitua FX conhecida. 4. Derive para obter fY(y).

Nas questões 6-8, X ~ exp(θ) na convenção taxa: FX(x)=1−e−θx, fX(x)=θe−θx.

Lista 3 — Questão 6 (Weibull)

X~exp(θ), Y = X1/γ. Determine a fdp de Y.

FY(y)=P(X1/γ<=y)=P(X<=yγ)=1−e−θyγ. Derivando:

fY(y) = θγ · yγ−1 · e−θyγ,  y>0  (Weibull)

Lista 3 — Questão 7 (Rayleigh)

X~exp(θ), Y = (2X/θ)1/2. Determine a fdp de Y.

Y2=2X/θ = X=θy2/2. FY(y)=1−e−θ2y2/2. Derivando:

fY(y) = θ2 · y · e−θ2y2/2,  y>0  (Rayleigh)

Lista 3 — Questão 8 (Gumbel)

X~exp(1), Y = α + γ·ln(X). Determine a fdp de Y.

ln X <= (y−α)/γ = X <= e(y−α)/γ. FY(y)=1−exp(−e(y−α)/γ). Derivando:

fY(y) = (1/γ) · exp((y−α)/γ) · exp(−e(y−α)/γ)  (Gumbel)

Módulo 8 — Distribuições Amostrais e Teorema Central do Limite

Média amostral X̄ = (X1+...+Xn)/n. Fatos fundamentais:

E(X̄) = μ     Var(X̄) = σ2/n     erro-padrão = σ/sqrt(n)
TCL: para n grande (>=30), X̄ é aprox. Normal(μ, σ2/n) independente da distribuição original. Se os dados já são Normais, é exato para qualquer n.

Padronização: Z = (X̄ − μ)/(σ/sqrt(n)). Para a exponencial, desvio-padrão = média.

Lista 2 — Questão 1

Sinistros ~ Normal(μ=12.000, σ=3.000). Amostra n=36. (a) Distribuição de X̄. (b) P(X̄>13.000). (c) Interprete.

(a) Dados Normais = X̄ exata: Var(X̄)=30002/36=250.000, erro-padrão=500. X̄ ~ N(12.000, 5002).

(b) Z = (13000−12000)/500 = 2,0.

P(X̄ > 13000) = P(Z > 2) = 1 − 0,9772 = 0,0228

(c) ~2,3% de chance da média de 36 sinistros passar de 13.000. Observar isso na prática seria um alerta de deterioração da carteira.

Lista 2 — Questão 2

Sinistros exponenciais, média 8.000 (forte assimetria). Amostra n=64. P(média entre 7.000 e 9.500)?

Exp: σ = média = 8000. n=64 >= 30 = TCL justifica a Normal. Erro-padrão = 8000/8 = 1000. X̄ ~ N(8000, 10002).

Z1 = (7000−8000)/1000 = −1,0 ; Z2 = (9500−8000)/1000 = 1,5.

P(−1 < Z < 1,5) = 0,9332 − 0,1587 = 0,7745

Lista 2 — Questão 3

Prêmio médio μ=2.500, σ=1.200. Amostra n=100. P(|X̄ − μ| < 200)?

Erro-padrão = 1200/10 = 120. |X̄−μ|<200 quer dizer |Z| < 200/120 = 1,67.

P(|Z| < 1,67) = 2·Φ(1,67) − 1 = 2(0,9525) − 1 = 0,9050

(Sem reposição: o fator de correção de população finita aprox. 1 quando a população é grande — por isso "aproximadamente".)

Módulo 9 — Estatísticas de Ordem: Máximo e Mínimo (resseguro)

P(máx > x) = 1 − [F(x)]n   ·   P(mín > x) = [1 − F(x)]n

Resseguro acionado quer dizer que algum sinistro ultrapassa a retenção = o máximo ultrapassa a retenção. "Nenhum ultrapassa" = [F(retenção)]n.

Lista 2 — Questão 4

Sinistros ~ U(0,100). Retenção 80. n=5. M=máx. (a) P(nenhum ultrapassa). (b) P(resseguro acionado ao menos uma vez).

F(x)=x/100 = F(80)=0,8.

(a) P(M<=80) = (0,8)5 = 0,3277.   (b) P(M>80) = 1 − 0,3277 = 0,6723.

Lista 2 — Questão 5 (mínimo de exponenciais)

4 carteiras, T~exp (tempo médio 50 meses). T_mín = mín(T1,...,T4). (a) Distribuição de T_mín. (b) P(nenhum evento nos primeiros 10 meses).

(a) P(T_mín>t) = (e−t/50)4 = e−t/12,5 = Exponencial de média 12,5 meses.

Mínimo de n exponenciais (mesma taxa) é exponencial, com taxa = soma das taxas.

(b) P(T_mín>10) = e−10/12,5 = e−0,8 aprox. 0,4493.

Lista 2 — Questão 6 (máximo de Pareto)

X~Pareto, F(x)=1−(10/x)3, x>=10. n=20. M=máx. P(maior > 50 mil) vs P(um único > 50 mil).

Cauda P(X>x)=(10/x)3. Um único: P(X>50)=(0,2)3=0,008.

Máximo: P(M>50) = 1 − (0,992)20 aprox. 0,1484.

Comparação: a chance de algum dos 20 passar de 50 mil (14,8%) é ~18x maior que a de um único (0,8%). É a base do risco de "cauda": eventos raros individualmente tornam-se prováveis no agregado.

Módulo 10 — Probabilidade Condicional

P(A | B) = P(A e B) / P(B)

Quando A é mais restritivo que B (ex.: T>=50 dentro de T>=20), então A e B = A, logo P(T>=50 | T>=20) = P(T>=50)/P(T>=20).

Lista 3 — Questão 3

Tempo de vida T ~ U(0,70). Calcule P(T>=50 | T>=20).

Para U(0,70): P(T>=a) = (70−a)/70. Como 50>20:

P(T>=50 | T>=20) = (20/70)/(50/70) = 20/50 = 0,40
Sacada: a uniforme NÃO é "sem memória". P(T>=50) incondicional aprox. 0,286, mas condicionada a já ter vivido 20 anos sobe para 0,40. (Só a exponencial é memoryless.)
