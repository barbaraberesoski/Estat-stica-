# Estatística Inferencial — Guia de Estudo (Mirador)

Material completo de revisão para a prova, cobrindo as 3 listas do Prof. Edimilson.
Da teoria do zero à resolução detalhada das 27 questões.

## Arquivos

- **`estatistica_inferencial_mirador.pdf`** — o guia completo em PDF (pronto para imprimir/estudar).
- **`estatistica_inferencial_mirador.html`** — mesma versão em HTML (abre no navegador; dá para "Imprimir → Salvar como PDF").

## Como baixar o PDF no iPad/celular

1. Toque no arquivo `estatistica_inferencial_mirador.pdf` acima.
2. Toque no botão **Download** (ícone de seta para baixo, no canto superior direito da visualização).

## Conteúdo (10 módulos)

1. Fundamentos: Esperança, Variância e propriedades
2. Valor Esperado como critério de decisão
3. As 5 distribuições fundamentais
4. Funções de Distribuição (FDA/CDF) e constantes normalizadoras
5. Função Geradora de Momentos (FGM)
6. Soma de variáveis via FGM
7. Transformações de variáveis (Weibull, Rayleigh, Gumbel)
8. Distribuições Amostrais e Teorema Central do Limite
9. Estatísticas de Ordem: Máximo e Mínimo (resseguro)
10. Probabilidade Condicional

+ Resumo final com fórmulas-chave, armadilhas e gabarito-relâmpago.
